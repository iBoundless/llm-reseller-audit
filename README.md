# llm-reseller-audit

Скилл для [DeepSeek Harness](https://github.com/deepseek-ai): аудит стороннего LLM-эндпоинта — посредника, прокси, агрегатора. Отвечает на два вопроса: **отдаёт ли он заявленную модель** и **честен ли тариф**.

## Зачем

Цена в разы ниже официального прайса — обычная ситуация на рынке перепродажи API. Иногда это демпинг, иногда — другой апстрим, иногда — подмена модели на более дешёвую. Правдоподобный текст пишут все, поэтому «на глаз» это не проверяется: нужны детерминированные артефакты и эталон для сравнения.

## Что проверяется

| # | Сигнал | Как |
|---|---|---|
| 1 | Паспорт ответа | `id`, `model`, `system_fingerprint`, заголовки `Server`/`Via`/`X-*` |
| 2 | Токенизатор | `usage.prompt_tokens` на фиксированном тексте, два разных объёма |
| 3 | Способности | vision (OCR цифр), needle на 118K, `reasoning_content`, `tool_calls` |
| 4 | Поведение | 10 задач с однозначными ответами при `temperature: 0` |
| 5 | Деньги | фактическое списание с баланса против колонки «Стоимость» |

## Быстрый старт

```powershell
# 1. эталон
powershell -ExecutionPolicy Bypass -File .\scripts\probe.ps1 -Name official `
  -BaseUrl https://api.deepseek.com -Model deepseek-flash -ApiKey "sk-..."

# 2. посредник
powershell -ExecutionPolicy Bypass -File .\scripts\probe.ps1 -Name proxy `
  -BaseUrl <BASE_URL> -Model <MODEL> -ApiKey "sk-..."

# 3. сравнение
powershell -ExecutionPolicy Bypass -File .\scripts\probe.ps1 -Compare ".\probe-official.json,.\probe-proxy.json"
```

Дальше — поведенческая батарея тем же способом (`battery.ps1`), затем сверка баланса. Подробности, пороги интерпретации и список известных ловушек — в [SKILL.md](SKILL.md).

## Требования

- Windows, PowerShell 5.1 или 7+.
- Никаких внешних зависимостей: только `System.Net.Http` и `System.Drawing` из состава .NET Framework.
- Ключи к обоим эндпоинтам: без эталона результат не интерпретируется.

## Ограничения

- Написан под OpenAI-совместимый `/v1/chat/completions`. Для Anthropic-формата меняется путь и заголовок, логика сигналов остаётся той же.
- `logprobs` проверяются только если их отдаёт сам вендор: у DeepSeek, например, поля нет, и сигнал недоступен.
- Скилл проверяет подлинность модели, но не юридическую чистоту посредника: он видит каждый ваш промпт.

## Структура

```
SKILL.md          — инструкция: сигналы, порядок, интерпретация, ловушки
scripts/probe.ps1 — паспорт эндпоинта (7 запросов)
scripts/battery.ps1 — 10 задач с объективной проверкой ответа
```
