# Аудит LLM-посредника

Подмену модели нельзя ловить «на глаз»: правдоподобный текст пишут все. Решают детерминированные артефакты, сравнённые с эталоном — официальным API той же модели.

**Главное правило:** без второго прогона на официальном эндпоинте никакие цифры не интерпретируются. Карточка одиночного прогона — это набор чисел без смысла.

## Когда применять

- Цена у посредника ниже официального прайса в 3+ раза — экономически это возможно только за счёт другого апстрима, демпинга или подмены.
- Нужно сравнить два OpenAI-совместимых эндпоинта на одну и ту же модель.
- Посредник сменил канал/провайдера, и качество «поехало».
- Перед предоплатой: платить вперёд неизвестному прокси — плохая идея.

## Когда не применять

- Официальный API вендора — там проверять нечего.
- Вопрос только про цену и скорость: достаточно прайса и замера задержки.

## Пять независимых сигналов

Проверять надо все пять: каждый по отдельности ложен, вместе — почти приговор.

| # | Сигнал | Что смотреть |
|---|---|---|
| 1 | Паспорт ответа | `id` (формат), `model` (как эхо), `system_fingerprint`, заголовки `Server`, `Via`, `X-*` |
| 2 | Токенизатор | `usage.prompt_tokens` на **фиксированном** тексте: совпало до единицы — та же семья |
| 3 | Способности | vision (OCR цифр), длинный контекст (needle на 118K), `reasoning_content`, `tool_calls` |
| 4 | Поведение | 10 задач с однозначными ответами при `temperature: 0` — совпадение дословно |
| 5 | Деньги | фактическое списание с баланса против колонки «Стоимость» |

Сигнал 2 — самый дешёвый и самый сильный: другой токенизатор почти всегда даёт другое число токенов на том же тексте.

## Порядок работы

Скрипты лежат в каталоге скилла, `scripts\`; команды ниже выполняются из этого каталога. Путь зависит от харнесса: `~/.dsh/skills/llm-reseller-audit` в DeepSeek Harness, `~/.claude/skills/llm-reseller-audit` в Claude Code, `~/.agents/skills/llm-reseller-audit` — кросс-рантайм алиас. Агент не нужен: скрипты запускаются и вручную.

### 1. Снять эталон

```powershell
powershell -ExecutionPolicy Bypass -File scripts\probe.ps1 -Name official -BaseUrl https://api.deepseek.com -Model deepseek-flash -ApiKey "sk-..."
```

### 2. Снять карточку посредника

```powershell
powershell -ExecutionPolicy Bypass -File scripts\probe.ps1 -Name proxy -BaseUrl <BASE_URL> -Model <MODEL> -ApiKey "sk-..."
```

### 3. Сравнить

```powershell
powershell -ExecutionPolicy Bypass -File scripts\probe.ps1 -Compare ".\probe-official.json,.\probe-proxy.json"
```

### 4. Поведенческая батарея (обе стороны)

```powershell
powershell -ExecutionPolicy Bypass -File scripts\battery.ps1 -Name official -BaseUrl https://api.deepseek.com -Model deepseek-flash -ApiKey "sk-..."
powershell -ExecutionPolicy Bypass -File scripts\battery.ps1 -Name proxy -BaseUrl <BASE_URL> -Model <MODEL> -ApiKey "sk-..."
powershell -ExecutionPolicy Bypass -File scripts\battery.ps1 -Compare ".\battery-official.json,.\battery-proxy.json"
```

### 5. Сверить баланс

Баланс до и после одного прогона. Колонка «Стоимость» в кабинете может быть декоративной.

## Как читать результат

| Что видно | Вывод |
|---|---|
| `prompt_tokens` совпал (±0–2) на двух разных объёмах | тот же токенизатор, скорее всего те же веса |
| `prompt_tokens` расходится на 15 %+ | другая модель или другая семья |
| `model` в ответе — чужое имя (`deepseek-ai/...` вместо `deepseek-flash`) | запрос идёт не напрямую к вендору, а через агрегатор |
| `system_fingerprint` есть у вендора и нет у посредника | нормально для прокси: поле не пробрасывают |
| `id` другого формата, `Server: cloudflare` вместо `elb` | своя шина, это не про модель |
| vision/контекст/reasoning/tools совпали | набор способностей тот же |
| батарея: 9–10/10 у обоих и 7+ совпадений дословно | одна и та же модель |
| батарея: расхождение 5+ задач | разные веса, при любых совпавших способностях |
| цена в 10+ раз ниже прайса при той же модели | демпинг, грант или прайс-лист временный: не платить вперёд |

Способности **не** доказывают подлинность: дешёвая модель тоже может уметь vision и 128K контекста. Токенизатор и батарея доказывают, способности — только опровергают грубую подмену.

## Дополнительные проверки

Если базовых пяти сигналов не хватило (результаты противоречивы, или речь о чувствительных данных):

- **Приватность.** Посредник видит каждый промпт и может логировать его. При любом исходе аудита — не отправлять через него персональные данные, ключи, внутренние документы.
- **Детерминизм.** 3–5 прогонов одного промпта при `temperature: 0` и `seed`. Побайтовое расхождение — нормально; расхождение в *содержании* намекает на ротацию апстримов между запросами.
- **Формат ошибок.** Неверный ключ, несуществующая модель, слишком большой `max_tokens` — вендор отдаёт узнаваемый `error.type`. Клон отдаст чужой шаблон.
- **Граница контекста.** Если 118K прошло, а 300K — нет, заявленный 1M не подтверждён: бинарным поиском найти реальный кэп.
- **Бета-эндпоинты.** FIM/prefix completion, если они есть у вендора, работают только при реальном passthrough.
- **`logprobs`.** Проверять сначала на официальном API: если вендор их не отдаёт, сигнал недоступен и в сравнение не идёт (так было с DeepSeek — `supported: false`).

## Ловушки, на которых уже ломались

| Симптом | Причина | Лечение |
|---|---|---|
| `401 Invalid token`, хотя ключ рабочий | запуск из `cmd.exe`: одинарные кавычки там не кавычки, в токен попали апострофы | только двойные кавычки, или запуск из PowerShell |
| `NEEDLE LOST` на большом контексте | в thinking-режиме `max_tokens` ушёл на рассуждение, `content` пуст, `finish_reason: length` | `max_tokens` 600+, или `-NoThinking` |
| `vision: 200:` с пустым ответом | то же самое | то же самое |
| `prompt_tokens` подозрительно велик | .ps1 записан в UTF-8 **без BOM**, PowerShell 5.1 прочитал как ANSI, кириллица уехала мусором | перезаписать файл с BOM |
| таблица сравнения схлопнулась в одну колонку | имена карточек с дефисом (`proxy-a`) не годятся в имена свойств | вертикальный вывод (уже в скриптах) |
| `524` через ~120 с | Cloudflare оборвал: origin не ответил | ретрай; это про нестабильность канала, не про модель |
| `temperature` будто не работает | в thinking-режиме он игнорируется | для сравнения — `-NoThinking` |

## Что делать с выводами

1. **Модель та же, цена ниже** — пользоваться, но без крупной предоплаты, и держать официальный ключ под рукой: переключение — одна строка `-BaseUrl`.
2. **Модель та же, но медленнее в 3+ раза** — для чата терпимо, для агента с десятками вызовов подряд считать задержку как издержку.
3. **Модель другая** — не использовать там, где нужна именно она; для черновиков и рутины может сгодиться.
4. **Деньги не сходятся** — колонка «Стоимость» врёт, реальная цена в другом месте: смотреть баланс, а не отчёт.

## Что отдавать заказчику

Короткая сводка: совпало/не совпало по каждому из пяти сигналов, итоговый вердикт одной фразой, и три числа — цена за день у посредника, цена за тот же объём по официальному прайсу, отношение между ними. Скрипты и JSON-карточки приложить: они воспроизводимы.
